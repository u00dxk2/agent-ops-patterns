# Screens: every page the hosted site serves

The site is GitHub Pages serving this repository's `main` branch as files (`.nojekyll`: nothing is rendered or
rewritten). There is no sign-in, no payment, no form and no stored data. Two pages carry a script, the OpenHands map and
its first edition (`gallery/openhands/index.html`, `gallery/openhands/edition-1/index.html`); no other page does. No page has
an empty, loading or error state of its own; a wrong address gets the 404.

The new layout ("the register", design pass 2026-11-17) is four stylesheets under `design/`, all written by
`scripts/build-design-variants.mjs`: `plan-c.css` for the front page, `gallery.css` for the gallery page (added
2026-11-18), `card.css` for the short cards and `map.css` for the full map pages (added 2026-11-20). A page is in the
new layout only if its `<head>` links one of them.
No page's words changed when it moved; the visible text and the accessibility tree were compared against `main`
before each move.

live-site check · **NEXT** = to move, with a date to re-check · **HOLD** = not moving
