# Screens: every page the hosted site serves

The site is GitHub Pages serving this repository's `main` branch as files (`.nojekyll`: nothing is rendered or
rewritten). There is no sign-in, no payment, no form, no script and no stored data, so every page is seen by a
visitor in the same state: there are no empty, loading, error or success states beyond "the page" and the 404.

The new layout ("the register", design pass 2026-11-17) is two stylesheets under `design/`: `plan-c.css` for the
front page and `card.css` for the short cards. A page is in the new layout only if its `<head>` links one of them.
No page's words changed when it moved; the visible text and the accessibility tree were compared against `main`
before each move.

Status: **DONE** = in the new layout and live · **NEXT** = to move, with a date to re-check · **HOLD** = not moving
yet, and why · **UNREACHED** = served, but not a page this repository designs.
