agent-ops-patterns

Maps of who decides what inside open-source agent systems, and the skill to make one of your own.

The gallery

Each map lists the recurring judgments in one system and who holds each (code, a model, or a person). The OpenHands map also records how each has failed and what checks it where the mapping found them, the prompt pieces and assembly paths identified in the mapped source for the seats a model holds, and a report of what the mapping exposed, and it quotes prompt source text on 14 of its cards, each quote linked to the lines it came from. The Cline map is a shorter edition with no gap report.

Make your own

The cog-ops-map skill has your agent map a system you work on. In Claude Code:

claude plugin marketplace add u00dxk2/agent-ops-patterns
claude plugin install agent-ops-skills@agent-ops-patterns

The method is "Cognitive Operations Maps".
