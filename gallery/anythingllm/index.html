AnythingLLM: who decides what

The gallery · Make a map of your own system · The repository

The AnythingLLM server's agent and chat decisions (its agent loop and tools, chat and agent endpoints, retrieval and memory, agent flows, MCP bridge, scheduled jobs, Telegram bot and model providers) in Mintplex-Labs/anything-llm, read at commit d7d68e75. The web frontend and document collector are outside this map except where a decision reaches the server. Claims about how the code behaves refer to that commit. Their code is MIT-licensed; this page quotes short identifiers and cites files and lines at that commit.

How to read this page

A seat is a judgment the system makes over and over: is this message a command, what the model sees, may this action run, is the work done. Each card records the question, how it is answered, and who or what holds it, with the code that implements or exposes that decision. Seat ids (A1, B12 …) are links.

The chip on each card has two words. The first is about the question: a RULE has one right answer given its inputs, so a run that answers differently is a bug; a RULING is one that competent people could answer differently. Enforcing a limit someone set is a RULE; choosing what to keep, what to trust or when the work is done is a RULING, even when code holds it.

The second word is who holds it: llm = a language-model call; model = another learned model; code = code in their repository; human = a person; external = code outside the repository that the system hands the decision to.

Paths are relative to the repository root. A bare :120-140 means lines in the file named just before it.
